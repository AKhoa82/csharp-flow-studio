# C# Path Builder

Design a complete, modern, professional web application UI/UX for a C# Self-Learning Platform – Content Management Module.

The system is an educational platform for learning C# programming and Object-Oriented Programming (OOP). The main purpose of this module is to manage and deliver learning content, courses, chapters, lessons, learning resources, question banks, quizzes/tests, and AI-assisted educational content.

The UI should look like a high-quality commercial EdTech SaaS product, not like a basic CRUD admin dashboard.

1. Overall Design Direction

Create a clean, modern, premium educational platform inspired by products such as Notion, Linear, Vercel, Coursera, Duolingo, and modern SaaS dashboards.
